# Контракт качества NovaCraft

Дата: 27 ноября 2026 года  
Рабочая ветка: `nova/refined-interface`

## Правило достоверности

Ни одна функция не считается готовой только потому, что:
- для неё создан экран или кнопка;
- исходники компилируются;
- CI создал EXE;
- функция описана в README.

Для статуса «проверено» нужны относящиеся к функции тесты и воспроизводимый сценарий проверки. Компиляция и тест установщика не доказывают, что Minecraft реально запустился с импортированным пакетом.

## Безопасность данных и изоляция

1. У каждой сборки отдельный `GameDirectory`. Моды, конфиги, версии, resource packs и shader packs записываются только в активный профиль.
2. Переключение сборки сверху должно менять активный профиль, путь Minecraft, версию и загрузчик.
3. Мир для datapack должен находиться внутри `saves` активной сборки. При переключении профиля выбор мира сбрасывается.
4. Удаление сборки удаляет только запись профиля. Папка с файлами и мирами остаётся на диске.
5. Импорт должен ограничивать пути, размер распаковки, дубликаты и символические ссылки.
6. CurseForge API-ключ вводится пользователем, передаётся только в HTTPS-запросы к официальному API/CDN и не записывается в settings.json, логи или диагностический отчёт.
7. Нельзя автоматически скачивать драйверы, менять реестр, отключать Windows Defender, запускать скрытые фоновые службы или устанавливать программы без явного действия пользователя.

- [ ] Runtime-проверка запуска Minecraft для нескольких профилей на реальной Windows-машине.

### Modrinth
- [x] Чтение `.mrpack` и `modrinth.index.json`.
- [x] Проверка Minecraft version и loader из манифеста.
- [x] Проверка SHA-512 и HTTPS CDN.
- [x] Установка обязательных файлов в отдельную папку сборки.
- [x] Поддержка `overrides` и `client-overrides` с ограничениями.
- [ ] Полный импорт и фактический запуск разных публичных сборок с их наборами модов.
- [ ] Тестирование всех loader/version сочетаний на Windows.

### CurseForge
- [x] Чтение экспортированного CurseForge ZIP с `manifest.json` и `overrides`.
- [x] Извлечение Minecraft version, Forge version и обязательных file IDs.
- [x] Запрос метаданных файлов через официальный API с пользовательским ключом.
- [x] SHA-1, проверка JAR-сигнатуры, ограниченный HTTPS CDN redirect.
- [x] Ключ не сохраняется в файле настроек.
- [ ] Встроенный поиск каталога CurseForge — не реализован.
- [ ] Файлы, для которых автор запретил стороннюю загрузку, требуют отдельного допустимого способа получения и не должны обходиться.
- [ ] Реальный импорт с одобренным CurseForge API-ключом ещё не проверен в живой среде.

### Разрешение экрана
- [x] Режим по умолчанию использует разрешение основного монитора Windows при создании параметров запуска.
- [x] Сохранён ручной режим разрешения.
- [ ] Проверка с несколькими мониторами и нестандартным DPI на пользовательском ПК.
- В исходниках нельзя подменять разрешение пользователя предположением. Точное значение определяется на его Windows-машине.

### Очередь загрузок
- [x] Отдельный экран «Загрузки».
- [x] Для задачи показываются источник, имя файла, целевая сборка и статус.
- [x] Для файлов Modrinth прогресс обновляется по фактическому потоку загрузки.
- [x] Есть статусы проверки, установки, успеха и ошибки.
- [x] Карточки обновляются на месте, без пересоздания всего списка при каждом проценте.
- [ ] Отмена, пауза, возобновление и сохранение очереди после перезапуска.
- [ ] Отображение общей скорости и оставшегося времени для каждой задачи.

## Функции, которые нельзя объявлять завершёнными

- Вход в Microsoft, Ely.by и синхронизация онлайн-скинов.
- Полноценная библиотека скинов и менеджер скинов по каждой сборке.
- Музыкальный плеер с плейлистами, обложками и управлением воспроизведением.
- Встроенная озвучка событий лаунчера и настраиваемые звуки запуска.
- Настоящие 3D-анимации и совпадение всех экранов с визуальным эталоном.
- Отдельный Java-мод оптимизации, проверенный на Radeon HD 6900 и ограниченной памяти.
- Автоматический ремонт драйверов. Допустима только диагностика с показом версии, состояния и официальной страницы производителя; скрытая установка драйверов запрещена.
- Гарантированный прирост FPS. Он зависит от карты, процессора, версии Minecraft, загрузчика, модов и параметров мира.

## Проверка и доказательства

Для каждого изменения сохранять:
1. commit SHA;
2. номер и URL GitHub Actions run;
3. результат шага сборки;
4. результат unit tests;
5. результат установочного smoke test;
6. список того, что тест не покрывает.

Текущая проверка CI — это проверка компиляции, unit tests, упаковки, установки, старта процесса EXE и удаления установщика. Она сама по себе не доказывает совместимость каждого Minecraft modpack или запуск Minecraft в пользовательской конфигурации.

## Визуальный эталон

Визуальный эталон NovaCraft — восьмиэкранный макет, созданный и показанный в переписке 27 ноября 2026 года: главная, сборки, моды, загрузки, паки/шейдеры, скины, музыка, настройки/исправление.

Проверка совпадения должна выполняться отдельно по каждому экрану: расположение, размеры, иерархия, цвета, плотность информации, состояния элементов, загрузки и ошибки. Не засчитывать декоративную картинку вместо работающего элемента.
